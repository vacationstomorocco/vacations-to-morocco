# Morocco Website — Editorial Redesign

## What changed
- Completely rebuilt the homepage with a distinctive dark-green/sand editorial visual system, scenic hero, simple travel copy, private tour cards, destination gallery, Sahara storytelling, reasons to book, and contact CTA.
- Updated homepage SEO title/description and removed the old homepage's unverified aggregate review schema.
- Refreshed the navigation's booking label and selected colors.
- Mobile responsive styles added for the new homepage.
- Uses local images already in your project and links to existing routes.

## Important
- Existing inner pages, blog, form logic, logos, and overall brand **Moroccan Tour Company** are preserved, not all redesigned.
- Reference travelmoroccovacation.com was used only as a thematic/content reference, not copied.
- This source is a Next.js app. Deploy to hosting that supports Node/Next.js or build according to your hosting setup; it is not a static HTML ZIP.
- Before launch, verify actual tour routes, tour claims, image rights, contact details, SEO domain, and company identity; these currently come from the original code.
- Run `npm install`, `npm run build`, then `npm run start` (requires a compatible Node.js environment).
